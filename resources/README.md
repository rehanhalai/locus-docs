# Resources & Forensic Library Index

This directory holds external documentation, academic research papers, and standardized benchmark datasets used to develop and validate Locus.

---

## Library Notes:

1. **[`reading-resources.md`](./reading-resources.md)**  
   *Academic Research Papers, Field Guides & Legal Authorities:*
   * **Indian Casework Guides:** ForensicSpot DVR/NVR Forensics (State FSL & CFSL protocols).
   * **Research Papers:** MDPI 2025 automated recovery paper, MDPI Journal of Forensic Sciences (`DHAV` binary headers), Digital Forensics Magazine (`HKFS` B+ Tree).
   * **Statutory Frameworks:** Bharatiya Sakshya Adhiniyam (BSA) 2023 Section 63/119 and Supreme Court precedents (*Anvar P.V.*, *Tomaso Bruno*).

2. **[`datasets.md`](./datasets.md)**  
   *Forensic Test Images & Benchmark Datasets:*
   * **NIST CFReDS File Carving Benchmarks:** Direct download links for `L0_Video.dd` through `L5_Video.dd` (braided/interleaved multi-camera CCTV).
   * **NIST Heimvision K9604-1 DVR Image:** Authentic 150 GB (2.0 GB `.E01`) 4-camera 24-hour continuous surveillance image with ground-truth CSV hash lists.
   * **DFRWS & NIST String Search Test Images:** Reference datasets for partition boundary and signature search validation.
